# 工作台紧凑导航实现计划

> **面向 AI 代理的工作者：** 必须使用 `superpowers:executing-plans` 在当前会话逐项执行，并在完成后运行页面与构建验证。

**目标：** 将工作台改为 Demo 所示的紧凑分组导航，让常规权限账号在首屏看到全部模块入口、搜索和常用操作。

**架构：** 只修改 `src/views/dashboard/index.vue` 的模板、样式和本地计算数据。继续复用 `NAV_GROUPS`、`auth.hasModule`、当前路由路径与搜索过滤逻辑，不触碰后端、权限模型和路由表。

**技术栈：** Vue 3、TypeScript、Element Plus、Vite。

---

### 任务 1：重组工作台信息层级

**文件：**
- 修改：`src/views/dashboard/index.vue`

- [ ] **步骤 1：将欢迎区改为低高度信息头**

保留 `initial`、`displayName`、`greeting`、`today` 和最近登录信息；以日期小字、问候标题、分公司/角色元数据组成两列头部，窄屏时自然堆叠。

- [ ] **步骤 2：将搜索并入功能导航标题行**

保持 `keyword`、`filteredGroups` 与 `searchEmpty` 计算逻辑不变，把 `el-input` 放在功能导航标题的右侧；输入框提示为“搜索功能、模块或关键字”。

- [ ] **步骤 3：将模块卡片改为分组内紧凑入口**

在每个 `filteredGroups` 分组下保留 `v-for`、`item.key` 和 `router.push(item.path)`；入口只显示图标与模块名称，使用两列网格并移除长描述文本，减少单项高度。

- [ ] **步骤 4：将快捷操作收束为低高度按钮行**

继续从 `quickActions` 渲染且继续按 `auth.hasModule` 过滤；移除描述和箭头，仅显示图标与明确动作名称。

### 任务 2：实现桌面与移动端紧凑样式

**文件：**
- 修改：`src/views/dashboard/index.vue`

- [ ] **步骤 1：替换工作台 CSS 变量与布局样式**

将页面最大宽度设为约 1180px，统一使用浅灰页面背景、白色导航面板、细边框和 `12px` 圆角；分组在桌面端最多三列、每组入口两列。

- [ ] **步骤 2：实现可访问的交互状态**

为模块入口和快捷按钮保留 `:hover`、`:active`、`:focus-visible` 状态；悬停只使用边框、浅色背景和小幅阴影变化，不造成布局跳动。

- [ ] **步骤 3：实现响应式断点**

在约 960px 宽度时将业务分组改为两列，在 640px 以下改为单列；搜索框改为整行，组内模块入口仍保留两列并避免横向溢出。

### 任务 3：验证权限、搜索与首屏密度

**文件：**
- 验证：`src/views/dashboard/index.vue`

- [ ] **步骤 1：运行 TypeScript 与生产构建**

运行：`npm run build`

预期：`vue-tsc -b && vite build` 以退出码 0 完成。

- [ ] **步骤 2：用 Playwright 检查工作台页面**

以已登录的测试会话访问 `/dashboard`，等待网络空闲后截取桌面和手机视口截图；检查搜索框、业务分组、模块入口、快捷操作和无横向滚动。

- [ ] **步骤 3：手动检查权限过滤与搜索**

使用当前测试账号确认只显示有权限的入口；输入模块名称的一部分，确认分组和入口正确过滤，并确认无结果状态可见。
