# 前端错误展示统一化实现计划

> **面向 AI 代理的工作者：** 使用执行计划流程逐项实施与验证。
**目标：** 统一处理 API 失败并避免页面重复展示技术错误。
**架构：** 在请求层将 Axios 错误规范化为 `QmsRequestError`；页面捕获该错误时只补充本操作的业务语义，不再展示原始网络文本。
**技术栈：** Vue 3、TypeScript、Axios、Element Plus、Playwright。
