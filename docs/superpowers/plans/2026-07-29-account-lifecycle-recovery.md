# 停用账号角色恢复交互实现计划

> **面向 AI 代理的工作者：** 使用 `superpowers:executing-plans` 逐项实现并在每个检查点验证。

**目标：** 让已停用账号在原角色已删除时能直接更换角色后启用，并使账号管理操作的原因校验、取消和列表状态一致。

**架构：** 前端负责将“角色不存在”业务错误转为角色更换对话框，并在保存有效角色后重试启用。后端继续作为角色有效性的最终校验。账号操作共用严格的原因输入与取消处理，列表只通过刷新服务端数据更新。

**技术栈：** Vue 3 Composition API、Element Plus、Axios、Spring Boot、JUnit 5、Vitest。
