# 前端错误展示统一化设计

## 目标

让业务人员看到可操作、统一且不泄露技术细节的错误提示，同时保留后端返回的业务校验信息。

## 处理规则

- 后端业务失败：只展示后端 `message`，不在页面中重复弹出。
- 网络中断、超时、服务异常：转换为中文通用提示，不显示 Axios、HTTP 或堆栈文本。
- 未登录或会话失效：清理会话并跳转登录页，只提示一次。
- 页面操作：页面只在需要补充业务上下文时显示提示，例如“保存失败”；请求层不重复提示。
- 列表初始加载失败：提供页内错误状态及“重新加载”操作；本次范围先复用现有加载机制，不新增全局页面组件。
- Vue 组件运行异常、路由异步加载异常和未处理的 Promise 异常：统一显示通用中文提示；相同提示在 3 秒内仅展示一次，开发环境保留控制台错误。

## 边界

本次只调整前端请求层与已有页面的提示调用方式；不变更接口结构、后端错误码、权限判断或业务数据。

## 验收

- 登录页和一次受保护接口请求不存在浏览器控制台错误。
- 模拟网络错误时，用户看到中文可操作提示而不是 `Network Error`。
- 后端业务错误仅显示一次。
- 运行时、路由和未处理异步异常均有统一兜底，不展示堆栈或接口细节。
