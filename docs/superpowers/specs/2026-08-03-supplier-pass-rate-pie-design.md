# 供应商合格率分段扇形图设计

## 目标

将来料数据管理中的“供应商合格率排名”柱状图改为按合格率区间统计供应商数量的环形扇形图。用户点击区间后，弹出该区间内的供应商明细及准确的不合格率。

## 范围

- 保留现有供应商排名接口的时间范围筛选。
- 后端排名结果补充合格批次、不合格批次和不合格率字段。
- 前端 `SupplierRankChart.vue` 改为环形扇形图。
- 在来料看板中增加区间明细弹窗，不改变来料列表和其他图表。

## 区间规则

合格率使用后端返回的 `passRate`，按以下互斥区间分组：

| 区间 | 判定条件 |
| --- | --- |
| 100% | `passRate === 100` |
| 90%～99.99% | `90 <= passRate < 100` |
| 80%～89.99% | `80 <= passRate < 90` |
| 70%～79.99% | `70 <= passRate < 80` |
| 60%～69.99% | `60 <= passRate < 70` |
| 60%以下 | `passRate < 60` |

扇区数值为每个区间内的供应商数量，而不是批次数。没有供应商的区间不展示扇区，但图例保留区间名称和 0 数量。

## 后端数据契约

`SupplierRankItemVO` 保留现有字段，并新增：

- `qualifiedBatches`
- `unqualifiedBatches`
- `unqualifiedRate`

供应商排名 SQL 继续按当前分公司、软删除标记和可选日期范围过滤。`unqualifiedBatches` 只统计 `inspection_result = '不合格'`，`unqualifiedRate = unqualifiedBatches / totalBatches * 100`，保留两位小数。待审核记录仍计入总批次，但不会被计入合格或不合格批次。

## 前端交互

- `SupplierRankChart` 接收现有排名数组，客户端按区间聚合。
- 环形图 tooltip 展示区间、供应商数量和区间内平均合格率概览。
- 点击扇区向父组件发出区间和供应商列表。
- 父组件使用 `el-dialog` 展示明细表，表格列包括供应商名称、供应商编号、总批次、合格批次、不合格批次、合格率、不合格率。
- 明细按合格率升序排列，便于优先查看风险供应商。
- 数据为空时显示空状态，不渲染误导性的默认扇区。
- 日期范围、分公司切换和记录增删后的刷新逻辑保持现状。

## 错误处理与兼容

- 新增字段为空时，前端显示 `—`，不阻塞旧数据展示。
- 后端接口失败时沿用现有看板错误处理和 loading 状态。
- 不新增单独明细接口，避免点击扇区产生额外请求。

## 验证

- 后端编译及供应商排名接口测试，确认区间内统计字段和日期过滤正确。
- 前端类型检查，确认新 VO 字段和图表事件类型一致。
- 浏览器验证：扇区数量、100% 独立分段、点击弹窗、空数据和分公司切换。
